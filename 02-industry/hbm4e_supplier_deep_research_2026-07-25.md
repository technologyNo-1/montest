# SK海力士 HBM4E 全产业链深度调研:扩产放量下的投资细分

## 应用目标

支撑"未来 5 年 HBM4E 放量下该投哪个细分"的投资决策。倒推维度:技术路线 -> 垄断根基 -> 工艺 -> 瓶颈 -> 供应商 -> 情景 -> CAGR -> 递归推理 -> 投资含义。HBM 宏观市场见 [[semiconductor_2026_report]]。

## 摘要(核心结论)

- **HBM4E**:2026.06 交付 12 层样品,2027 量产配 NVIDIA Rubin,2027 占 HBM 需求 40%
- **海力士垄断**:市占率 52%,护城河 = MR-MUF 专利 + 台积电逻辑 die 绑定 + 英伟达锁单
- **反直觉发现**:TC Bonder 权威 CAGR 仅 **13%**,低于 HBM 整体 26.8%--设备类"卖铲人"CAGR 被单价稀释 + 替代预期压制
- **CAGR 最高(推断)**:Low-α 球粉 35-50%+、HBM 测试设备 30-40%+、Hybrid Bonding(极高但 2027 前基数小)
- **确定性最高**:CoWoS(产能硬约束,排期 2027 底)
- **投资含义**:短期(2025-27)TC bonder + 测试放量;长期(2027+)Hybrid bonding + 球粉;CAGR 最高押球粉/测试,确定性押 CoWoS/键合

## D1 技术路线与规格

- HBM4E:堆叠 12/16 层(当前),路线图至 20 层(HBM5)
- 工艺:核心 DRAM 1c(第 6 代 10nm 级),逻辑 base die 台积电 N3P(3nm)
- **关键变化**:逻辑 die 首次外协台积电(HBM3E 自研)-> 代工-存储深度绑定,定制化能力
- 时间线:2026.06 12 层样品 -> 2026H2 扩送样 -> 2027 量产(配 Rubin)
- HBM 需求 YoY:2026 +77%、2027 +68%(TrendForce/Chosun);HBM4E 2027 占 HBM 需求 40%

## D2 海力士垄断根基

- 市占率 52%(2026),收入 ~$595 亿
- **护城河四支柱**:
  1. **MR-MUF 专利**(独家堆叠工艺,良率优势,区别于三星 TC-NCF)
  2. **台积电逻辑 die 绑定**(HBM4 起 base die 用 N3P,定制 HBM 能力)
  3. **英伟达锁单**(Rubin 平台 ~70% 份额)
  4. **先发优势**(HBM3E 确立良率领先)
- **三星/美光差距**:
  - 三星:HBM4 量产推迟,自建 logic die 工艺,定制 HBM 领域可能反超
  - 美光:HBM4E 2027,DRAM + base die 自研,落后 1-2 季度
  - 中国(CXMT):仅 HBM3,落后 2-3 代
- **良率**:海力士高于三星/美光(MR-MUF 优势),确切数字未公开(付费报告)

## D3 制造工艺全流程

1. DRAM die 制造(1c 工艺)
2. TSV 刻蚀 + 铜电镀填充(深硅刻蚀 + drill-and-fill,Lam 独家设备)
3. 晶圆减薄(薄化到微米级,DISCO)
4. 键合堆叠(MR-MUF 12-16 层 / Hybrid Bonding ≥20 层)
5. 测试(CP/FT/SLT,Advantest V93000)
6. CoWoS 2.5D 集成(台积电,与 GPU 整合)

## D4 卡脖子瓶颈(核心)

| 瓶颈环节 | 性质 | 影响 |
|---|---|---|
| **CoWoS** | **最硬约束** | 台积电 2025 底 ~12 万片/月,排期 2027 底,产能 = 供给天花板,决定整线产能 |
| **键合精度** | 技术极限 | TC bonder 对准精度 sub-1μm,≥16 层逼近极限,需 hybrid bonding |
| **TSV 良率** | 良率制约 | 12 层以上良率损失风险(Mordor 定性 -1.9% 影响) |
| **测试时间** | 工时瓶颈 | 带宽 2.048Tb + 层数 + 良率压力,测试时间拉长,P&T7 200 台 4000 亿韩元印证 |

**瓶颈决定最受益**:CoWoS(确定性最高)+ 键合(扩产期弹性)+ 测试(放量弹性)。

## R1-R6 递归深挖推理(核心)

### R1 哪个最受益

- **CAGR 最高(推断)**:Low-α 球粉、HBM 测试设备
- **确定性最高**:CoWoS、键合设备
- **关键区分**:CAGR 最高 ≠ 弹性最大 ≠ 确定性最高--三个维度要分开看

### R2 为什么(物理/工艺本质)

- **TC Bonder CAGR 低(13%)的反直觉本质**:单价高(收入基数大,CAGR 分母大)+ 2028 后 hybrid 替代预期(压制远期)+ Hanmi 份额被 ASMPT/Hanwha 稀释(量被分)。设备类"卖铲人"CAGR 未必跑赢行业。
- **球粉 CAGR 高的本质**:耗材(持续消耗,非一次性)+ 8 倍消耗弹性(层数 + 芯片面积 + GMC 填充比例上升)+ **无技术切换风险**(hybrid bonding 时代仍需粉体填充)。耗材类弹性持续,设备类有代际切换风险。
- **测试 CAGR 高的本质**:测试时间随接口带宽(HBM4E 2.048Tb)+ 层数 + 堆叠良率压力上升而拉长,单堆测试资本开支数倍增长,且测试是强制环节无技术跳过。
- **CoWoS 确定性高的本质**:产能 = 供给天花板,无替代工艺,台积电独家大规模量产。

### R3 瓶颈缓解节奏

- **CoWoS**:台积电扩产,但排期 2027 底--**2 年瓶颈窗口**,期内确定性最高
- **键合**:hybrid bonding 2027-28 切换(HBM5 20 层),TC bonder 在 HBM4/4E(2025-27)仍是主战场
- **TSV**:良率随工艺成熟提升,12 层以上风险逐步解决
- **测试**:测试机产能随 Advantest 扩产,但测试复杂度升抵消部分产能

### R4 各细分放量情景

- **TC bonder**:2025-27 放量主升浪(确定性高),2028 后 hybrid 替代压力,CAGR 13%
- **Hybrid bonding**:2027-28 拐点,基数小 CAGR 高,但绝对规模 2027 前有限
- **球粉**:持续消耗,CAGR 推断 35-50%+,量价齐升,技术切换风险低
- **测试**:P&T7 放量,CAGR 推断 30-40%+,单堆测试资本开支数倍
- **CoWoS**:硬约束,确定性最高,CAGR 受台积电整体节奏制约(非纯 HBM)

### R5 结论边界(什么条件下反转)

- 球粉 CAGR 推断依赖"8 倍消耗"(待验证一手),若消耗弹性低于预期,CAGR 下调
- 测试 CAGR 推断依赖 P&T7 200 台 4000 亿韩元订单(待验证一手)
- **hybrid bonding 提前成熟** -> TC bonder 弹性窗口缩短(2027 前替代)
- **HBM 需求不及预期** -> 全细分 CAGR 下调
- **三星/美光追赶** -> 海力士份额稀释,供应链重构(三星用 SEMES 自家设备、NCF 路线)
- **CoWoS 产能提前释放** -> 硬约束缓解,但 HBM 需求仍是天花板

### R6 应用含义(投资决策)

| 策略 | 细分 | 标的 | 逻辑 |
|---|---|---|---|
| **CAGR 最高(推断)** | Low-α 球粉 | 联瑞新材(全球第二) | 8 倍消耗弹性,无技术切换风险 |
| **CAGR 最高(推断)** | HBM 测试设备 | Advantest | P&T7 放量,测试复杂度升 |
| **确定性最高** | CoWoS | 台积电 | 产能硬约束,排期 2027 底 |
| **短期弹性(2025-27)** | TC Bonder | Hanmi/ASMPT | 扩产主升浪,但 CAGR 被稀释 |
| **长期(2027+)** | Hybrid Bonding | Besi | HBM5 20 层切换,先发寡占 |
| **避开** | 硅片/光刻胶 | - | 占比低,弹性稀释 |
| **避开** | TIM | - | iHBM 自研散热替代风险 |

**国产替代(A 股逻辑,非全球龙头)**:华海诚科(GMC)、联瑞新材(球粉)、兴森科技(基板)--国产突破但全球非龙头,弹性看国产替代进度而非全球 CAGR。

## 核心洞察

1. **反直觉**:TC bonder 权威 CAGR(13%)< HBM 整体(26.8%)。设备类"卖铲人"CAGR 被单价稀释 + 替代预期压制;**耗材类(球粉)+ 测试类弹性更优**
2. **最受益分两类**:CAGR 最高(球粉/测试,推断)+ 确定性最高(CoWoS/键合)。投资要分清押 CAGR 还是押确定性
3. **CoWoS 是硬约束**:产能 = 供给天花板,决定整线产能,排期 2027 底
4. **时间窗口分层**:2025-27 TC bonder + 测试放量;2027+ hybrid bonding 接棒 + 球粉持续
5. **耗材 vs 设备本质差异**:耗材无技术切换风险(弹性持续),设备有代际切换风险(hybrid 替代 TC)
