## 一、项目推进状态：是否在推进？

**结论：是，且为顺网当前核心战略级业务。**

依据：
1. **战略定性**：2024 年 1 月正式将"顺网雲"升级为"顺网算力"，确立 **"立足算力，聚焦 AI"** 为公司核心战略（CEO 樊星博士 2024-03 开年大会重申）。
2. **官网一级导航**：首页"算力服务"与"AI 服务"并列为一级导航，与"网吧管理"并列，说明已从边缘业务升格为主航道。
3. **产品矩阵完整**：算力塔（管理平台）+ 算力市场（交易平台）+ 智算中心（AI INFRA）+ 云电脑（C 端）四件套已成型。
4. **持续投入**：2025 年研发投入 1.53 亿元、研发人员 438 人（占员工 1183 人的 37%）；投资活动现金流净额 -3.97 亿元（显著高于 2024 年约 -1.5 亿级别），指向基础设施投入。
5. **生态合作实质化**：华为、英特尔、广东电信、中国移动等均为具名、有具体产品/发布会的合作，非纸面 MOU。

**注意**：项目"在推进"≠"已规模化变现"。推进的是**平台与生态**，变现规模仍不可见（见 §六）。

## 三、算力如何回收与调度（技术机制）

### 3.1 算力回收机制（分层架构）

```
┌─────────────────────────────────────────────────────────┐
│  终端层（网吧侧）                                          │
│  网吧 PC ──网维大师（无盘管理，覆盖 10万+ 网吧）           │
│         └─顺网云电脑/电竞云电脑 客户端 Agent              │
│            · 将本地 GPU 算力"注册"到算力池                 │
│            · 接收云端任务分发                              │
│         GPU 经 虚拟化/容器化 池化（非纯透传，待核实细节）   │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│  边缘节点层                                                │
│  单个/区域内多个网吧组成边缘算力节点，就近计算与数据缓存     │
│  （瞬元 SiMETA 描述："全国数百万终端节点生态构成分布式网络"）│
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│  中心调度层                                                │
│  · 算力塔（SCC）：集群管理 + 分布式算力统一平台            │
│  · 顺网算力云：算力池统一管理，按时间段/性能切分复用        │
│  · 顺网智算（AI INFRA）：算力调度 + 模型推理部署 + API      │
│  · 智算中心（自建数据中心）：补充重负载训练/推理            │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│  开放北向接口 -> 对接下游业务（CaaS）                      │
└─────────────────────────────────────────────────────────┘
```

**关键点**：
- **入口是"网维大师"**--顺网旗下无盘管理系统，装机覆盖 10 万+ 网吧，是网吧 PC 的管理入口，也是算力回收的"天然抓手"。这解释了为什么顺网能做而别人难做：它早已掌控了网吧终端。
- **池化方式**：产品描述指向 **GPU 虚拟化 + 容器化混合方案**（"瘦终端/客户端向云端算力池按需调取算力"），但**无公开技术白皮书证实**是 vGPU 分片、还是 Docker/K8s on GPU、还是透传。
- **边缘 + 中心互补**：边缘算力（网吧夜间回收）适合低延迟、轻量任务；自建智算中心承担更重训练/推理负载。

### 3.2 调度机制

**算力塔（SCC）核心能力**：
- 计算资源统一纳管（普通 PC 集群 + 分布式节点统一入池）
- **云边协同**：中心端任务分发与资源匹配，边缘节点自主执行
- **灵活算力切分**：**按时间段、按性能切分，实现算力复用**--这是夜间闲置算力利用的关键机制
- 开放北向接口，快速对接第三方

**夜间复用逻辑（推断）**：
1. 网吧 Agent 上报状态（在线/空闲/繁忙、GPU 型号、负载、延迟）
2. 中心调度维护全局算力资源视图
3. 下游任务请求时，按任务类型（游戏渲染/AI 推理/离线计算）匹配最近的有余力边缘节点
4. **夜间非高峰时段，非实时任务（AI 推理、渲染）被优先调度到空闲网吧 PC**
5. 若 PC 被上机使用，系统需快速回收/切换（产品称"挂机切换设备直连，无需重启"）

### 3.3 网吧侧硬件与夜间窗口

- **硬件**：宣传"NVIDIA RTX 40/50 系列裸金属 GPU 算力支持"；Intel&顺网显卡实验室（2022）。典型网吧配置 RTX 3060~4090/50 系列，但型号分布无公开数据。
- **夜间窗口**：官方未定义。行业常识：网吧高峰 14:00-23:00，凌晨 0:00-8:00 上座率显著下降（通宵包夜上座率远低于白天）。"按时间段切分"暗示窗口可配置。
- **规模**：宣称 10 万+ 网吧装机量、万卡规模边缘平台、董事长口径"几百万台算力"愿景--但**实际接入算力池的比例、回收 PC 数、TFLOPS/PFLOPS 均无公开数据**。

### 3.4 技术层面的"宣传 vs 可证实"鸿沟

| 维度 | 宣传口径 | 可证实程度 |
|------|---------|-----------|
| 回收实现 | "算力池化、按需调取" | 无白皮书，vGPU/容器/透传未明确 |
| 调度切分 | "按时间段/性能切分复用" | 概念成立，实现细节未知 |
| 与通宵用户冲突 | "7x24 保障" | 抢占/回收策略无公开说明 |
| 规模 | "万卡""几百万台" | 装机量有，实际入池比例空白 |
| 延迟 | "毫秒级算网" | 无实测数据公开 |

## 五、费用如何结算

**结论：公开渠道与财报均未披露结算细节。以下为基于顺网商业模式的合理推断。**

### 5.1 网吧业主侧（供应端）

- **财报未披露分成比例**。
- **推断逻辑**：顺网一贯模式是"免费提供网吧计费系统/游戏更新软件，换取终端资源使用权（广告位、桌面入口），通过广告/增值服务变现"。算力回收大概率沿用此逻辑--**网吧贡献夜间闲置 GPU 算力，顺网技术调度后对外销售，网吧按算力贡献获得分成**。
- 但分成比例、计费方式（按贡献算力/时长/任务）、是否已规模化落地，**均无法证实**。

### 5.2 客户侧（需求端）

- **财报未披露计价方式**。无法确认是按 GPU 小时、按任务（渲染/推理作业）、按订阅、还是按资源包计费。价格水平无数据。
- 顺网云电脑 C 端有"5080 体验卡"等产品形态，指向订阅/时长计费，但这属云电脑消费，不直接等于"回收算力"的 B 端定价。

### 5.3 结算小结

> 结算是本项目最大的信息黑箱。网吧分成、客户计价、平台抽成三项均无公开数据。这意味着**无法从商业模型层面验证"网吧夜间算力整合"是否已形成可持续的现金流闭环**。

## 六、对公司利润的影响与规模

### 6.1 财务影响结论

**截至 2025 年报（2026-04-22 披露），算力/云业务尚未对顺网科技营收产生可单独观测的财务影响。**

- 财报按产品/服务分四大类：**网络广告及增值 / 游戏业务 / 展会业务 / 其他**。
- **算力业务未被单列为独立收入科目**。若已产生收入，最可能埋入"网络广告及增值"分部，但无法拆出。

### 6.3 季度趋势（值得注意的异常）

| 期间 | 营收(亿) | 毛利率 | 归母净利(亿) | 营收同比 |
|------|---------|--------|-------------|---------|

### 6.4 唯一的间接信号

- "网络广告及增值"分部毛利率从 26.31% -> 34.89%（+8.6pp），整体毛利率 41.13% -> 48.46%。
- **推测**：若算力/云服务属高毛利业务且占比提升，可能部分贡献了毛利率上行。但**广告业务自身优化、游戏业务高毛利拉动同样可解释**，无法归因，更无法量化。
- 投资活动现金流 -3.97 亿（vs 2024 约 -1.5 亿），指向基础设施投入加码，与算力战略方向一致，但同样非直接证据。

### 6.5 利润影响小结

> **净利润 +65.8% 的亮眼表现，主要来自毛利率提升与可能的费用/投资收益，而非算力业务的收入爆发**（算力收入若存在也埋在同比 -6.9% 的"网络广告及增值"里）。**截至最新可得财报，"网吧夜间算力整合"对利润的量化贡献=无法证实。**

## 七、概念与实质的鸿沟（关键风险提示）

这是本报告最重要的判断。顺网作为 A 股"算力概念股"，存在显著的**宣传口径与可证实数据之间的鸿沟**：

| 维度 | 市场/宣传认知 | 可证实的实质 |
|------|-------------|-------------|
| 整合规模 | "万卡""几百万台算力" | 仅装机量 10 万+网吧；实际入池比例/算力 PFLOPS 空白 |
| 下游客户 | 算力卖给 AI 公司/渲染厂 | 无任何具名付费客户披露 |
| 结算闭环 | 网吧分成、客户付费 | 分成比例、计价方式、价格均未披露 |
| 利润贡献 | 算力概念带动股价 | 财报未单列，营收占比不可见 |
| 技术实现 | 毫秒级算网、智能调度 | 无技术白皮书，vGPU/容器细节未知 |

**风险**：若未来财报持续不单列、运营指标持续不披露，则该业务可能长期停留在"战略叙事 + 生态合作"阶段，股价表现与基本面脱节的风险高。

## 八、与全球同类模式对比（顺网 vs AMP PBC）

顺网的"网吧夜间闲置算力整合"本质是**"算力电网"模式的中国先行案例**，与上一份调研中 a16z 的 Anjney Midha 创立的 **AMP PBC**（算力电网）是同一思想谱系：

| 维度 | 顺网科技（中国） | AMP PBC（美国，Midha，2026 创立） |
|------|----------------|----------------------------------|
| 资源来源 | 网吧夜间闲置 GPU | 企业闲置 GPU / 数据中心冗余 |
| 核心模式 | 边缘算力池化 + 中心调度 + 算力市场 | ISO（独立系统运营商）模式，算力作公用事业 |
| 起步时间 | 2017 起源，2024 战略升级 | 2026-03 GTC 公开 |
| 优势 | 已掌控 10 万+网吧终端入口（网维大师） | 资本新进入，理念先进但无存量抓手 |
| 透明度 | 规模/客户/结算不透明 | $1.3B 承诺资金已披露，运营数据待观察 |
| 金句对照 | "将整个行业几百万台算力集结起来"（华勇） | "Nobody builds their own power plant"（Midha） |

> **启示**：顺网的先发优势在于"早已掌控网吧终端"这一稀缺抓手；其短板在于公开透明度与商业化闭环的可验证性。两者都押注同一底层判断：**闲置算力池化是下一代基础设施**（参见同目录 `a16z_five_partners_synthesis.md` §七-7"基础设施/能源/算力是真正的瓶颈与最大机会"）。

## 九、待核实事项与数据局限

为保持诚实，列出本次调研盲区：

1. **"万卡规模""几百万台算力"** -- 是 GPU 卡数还是节点数？是否含网吧存量聚合？缺乏精确披露。
2. **日活"超百万级"**（2025-02 DeepSeek 接入）-- 是云电脑用户还是算力平台用户？C 端还是 B 端？未明确。
3. **算力业务收入拆分** -- 财报未单列，无法从"网络广告及增值"中拆出。
4. **实际整合规模** -- 已整合网吧节点数、GPU 卡数、算力 PFLOPS、回收率均未披露。
5. **结算细节** -- 网吧分成比例、客户计价方式、平台抽成、价格水平均无数据。
6. **下游付费客户** -- 无具名算力采购方；合作方≠客户。
7. **技术实现** -- vGPU/容器/透传方式、与通宵用户冲突处理、延迟实测均无公开白皮书。
8. **2026Q1 营收 -50.8% / 毛利率 69%** -- 反常，原因待核实（业务结构调整？确认时点？）。
9. **"全光毫秒算网"发布会（2026-05-14）后续落地** -- 截至 2026-07-15 官网未见后续报道。
10. **与英伟达合作深度** -- 2023-10 参观后无深度成果披露，不及华为/英特尔合作具体。

**公开素材覆盖度**：
- 时间线/战略/产品/合作：**高**
- 技术架构（宏观）：**中**；技术实现（微观）：**低**
- 财务分部数据：**高**（但算力未单列）；算力业务专项财务：**低**
- 下游客户：**低**；结算模式：**低**；实际运营规模：**低**

## 十、一页纸总结

- **推进中**：是。2024-01 升级为"顺网算力"主战略，产品/生态/合作三线落地，非概念炒作。
- **时间线**：2017 起源 -> 2024-01 战略升级（算力塔/市场/智算）-> 2025-02 拥抱 DeepSeek -> 2026-05 全光毫秒算网。
- **回收调度**：网维大师+Agent 入口 -> GPU 池化 -> 边缘节点 -> 算力塔中心调度，按时间段切分夜间复用。技术细节缺白皮书。
- **流向**：云游戏（主）、AI 推理、企业云电脑、教育/家庭/医疗/渲染。无具名付费客户。
- **结算**：未披露。推测沿用"免费软件换资源+分成"逻辑。
- **利润影响**：截至 2025 年报未单列、不可观测。净利 +65.8% 主因毛利率提升，非算力收入爆发。
- **核心判断**：真实推进的战略级业务，但规模/客户/结算/利润贡献四项核心数据不透明，需严格区分"概念"与"基本面"。
