## 4. 核心哲学体系

### 4.1 Build in Public（公开建造）

这是 Levels 最核心的信条——也是他影响力来源的根本机制：

> *"把所有东西都公开。收入、代码、失败、困惑。人们会信任你，因为他们能看到一切。"*

**实践方式：**
- 实时贴出 Stripe 收入仪表板截图——不做过滤，包括下跌
- 在 X/Twitter 上直播建造过程——飞行模拟器从第一行代码到上线全程可见
- 分享失败和困惑——"飞行模拟器收入归零了"同样公开
- 免费公开所有学到的东西——博客、播客、推特 thread

### 4.2 Solopreneurship 绝对主义

> *"我有零融资，所以我必须快速行动。我可以穿着内裤在酒店房间里发布产品。"*

| VC 路线 | Levels 路线 |
|---------|-----------|
| 融资 → 雇人 → 规模化 → 退出 | 自举 → 单人 → 盈利 → 自由 |
| 要做 PPT | 要发产品 |
| 对董事会负责 | 对自己负责 |
| 目标：十亿美元退出 | 目标：月入 $10 万 + 自由 |

**他认为 VC 模式在 AI 时代已经过时：**
- AI 让建造成本趋近于零 → 不再需要资金来雇工程师
- 一个人的公司可以做到 $3-5M ARR → 为什么稀释股份？
- VC 的钱 = 失去控制权 = 失去自由——而他最大的价值观就是自由

### 4.3 Boring Tech Stack（无聊技术栈）

> *"PHP + jQuery + SQLite。一直都是。AI 写的代码也是这个栈。"*

- 每个产品在 Hetzner VPS 上独立运行（€4/月起）
- 单文件架构：`index.php` 带 switch/case 路由
- SQLite 数据库——不需要 PostgreSQL/MySQL 集群
- 自定义队列系统——不需要 Redis/RabbitMQ
- 没有微服务、没有 Kubernetes、没有 CI/CD pipeline
- **总基础设施成本：~$384/月**

### 4.4 Vibe Coding = AI 100%（从工具到身份）

Levels 是最早接受并推广 Andrej Karpathy "Vibe Coding" 概念的人之一：

> *"我完全接受了 vibe coding——让 AI 写所有代码，我只关注产品和愿景。"*

**演进轨迹：**
```
2024 末：用 Cursor + Claude 辅助编码
2025.02：飞行模拟器——"Cursor 写前端，Grok 3 写服务端。100% AI 写的。"
2025.06：Claude Code 全自主维护——"我不碰代码"
2026.02：10x output——"一周清空了原来需要小团队的全部 backlog"
2026.05：宣言时刻——"我已经 6 个月没写过一行代码了。大家都这样了吧？"
```

### 4.5 欧洲加速主义（eu/acc）

2025 年 2 月发起的运动——不是产品，是一个意识形态宣言：

> *"欧洲有伟大的人才，但它被监管和政府天花板压垮了。这里有一种文化问题——做生意是坏的，赚钱是羞耻的。"*

**核心诉求：**
- 减少监管负担
- 跨国界统一的商业规则（整个 EU 一套规则）
- 英语作为 EU 主要工作语言
- 释放欧洲的技术潜力

### 4.6 Ship Fast, Fail Fast（快速发布，快速失败）

> *"如果你没有融资，你就必须快速行动。"*

- 3 小时原型 → 上线 → 看数据 → 决定是否继续
- 飞行模拟器：3 小时建造 → 17 天验证 → 归零 → 学到了 → 下一个
- **不做市场调研——从自己的需求出发。** "我是个数字游民，我需要知道哪个城市好 → Nomad List。我需要远程工作 → Remote OK。我想要 AI 生成的照片 → Photo AI。"

### 4.7 从软件到硬件——思想的转折

2026 年 6 月，他发出了一个转变信号：

> *"我取消了所有 SaaS 订阅，自己 vibe code 了替代品，免费……聪明人都在搞硬件，因为硬件仍然难进入。"*

这是对 AI 时代创业机会的根本性重估——软件建造成本趋向零 → 软件不再是护城河 → 真正的壁垒在物理世界。

## 6. AI 编码工作流（2025-2026 演进）

### 6.1 架构：VPS + Claude Code + Telegram

```
Pieter 的手机
    │
    │  Telegram 消息: "修一下 Photo AI 的付款 bug"
    ▼
┌──────────────────────────────────────────┐
│         Telegram Bot（中继层）             │
└──────────────────┬───────────────────────┘
                   │
    ┌──────────────┼──────────────┐
    ▼              ▼              ▼
┌─────────┐  ┌─────────┐  ┌─────────┐
│Hetzner 1│  │Hetzner 2│  │Hetzner N│
│Photo AI │  │NomadList│  │RemoteOK │
│         │  │         │  │         │
│Claude   │  │Claude   │  │Claude   │
│Code     │  │Code     │  │Code     │
│systemd  │  │systemd  │  │systemd  │
└─────────┘  └─────────┘  └─────────┘
```

- 每个产品有自己的 Hetzner VPS（€4/月起）
- Claude Code 作为 **systemd 服务**（自动启动/重启/不眠）
- Pieter 通过 **Telegram bot** 发指令 → bot 转发给对应产品的 Claude Code
- 24/7 AI ops engineer ——永不下班、不请假、不离职
- 总基础设施：~$384/月

### 6.2 "描述传递"方法

```
Project A（React/Tailwind）
    │
    │  让 Claude Code 描述功能的：
    │  - 逻辑流程
    │  - 交互行为
    │  - 数据结构
    │
    ▼
  自然语言描述（跨技术栈兼容）
    │
    ▼
Project B（PHP/jQuery）
    │
    │  粘贴描述 → Claude Code 在新的技术栈中实现
```

### 6.3 多 Session 并行

- 使用 **Termius** SSH 客户端同时跑 4+ 个 Claude Code session
- 每个 session 独立工作（不同任务并行）
- `SESSION.md` 文件保存上下文（跨 session 保持状态）
- 定期 `/compact`（压缩上下文，保留被拒绝的方法和关键决策）

## 8. 关键叙事线索

### 线索一：从 Coder 到 Conductor——身份的根本转变

```
写代码的人（2014-2024）
    → 用 AI 辅助写代码（2024-2025）
    → AI 写代码，我在旁边看（2025.02：飞行模拟器）
    → 我不碰代码了（2026.05：6 个月没写一行）
    → 我通过 Telegram 给 AI 发指令（2026：VPS + Claude Code + Telegram）
```

这是一个完整的人类→AI 指挥者的进化案例。Levels 不是"被 AI 取代"——他是主动退出了编码层，进入了更高层次的系统架构和产品决策。

### 线索二：病毒 × 不可持续 = 市场信号

飞行模拟器的完整生命周期（3 小时建造 → Elon 转发 → $87K MRR → $0）是 AI 时代最纯净的产品实验：

- **建造成本 ≈ 零**——3 小时一个人
- **分发成本 ≈ 零**——Elon 一个转发给了 219M 曝光
- **病毒 ≠ 退出**——当新奇退去，留存归零
- **但学到了**——AI 游戏可行、单人能做运营、Pietflare（DDoS 防御工具）也是副产品

### 线索三：软件商品化 → 护城河转移到硬件

这是他最重要的思想转向：

> *2025 年："我单人用 AI 造的 SaaS 年入百万——VC 模式过时了"*
> *2026 年："我取消了所有 SaaS 订阅，自己 vibe code 了替代品——软件免费了，壁垒在硬件"*

这是一个自我否决的逻辑：他证明了一个人 + AI 可以年入百万 → 所以其他人也可以 → 所以软件不再是壁垒 → 所以下一个机会在物理世界。这是 AI 时代的熊彼特创造性破坏在实时发生。

### 线索四：eu/acc——从创业者到运动领袖

eu/acc 不是一个产品，是一种意识形态。它标志着 Levels 从"做好自己的生意"升级到"改变欧洲的技术文化"。这不是产品 pivot——这是角色 pivot。

### 线索五："行为艺术"——对 VC 模式的最尖锐批判

Levels 在 5 月 25 日的推文中直接点名了一个 AI 创业公司（$30M Series A），指出其 ARR 声明在 90 天内从 $709K 跳到 "接近 $10M"。他称这种公司的运作方式为 "Sacha Baron Cohen 式的行为艺术"。

**他的论点不是道德判断，而是效率判断：**
- VC 泡沫让公司不需要真正的产品市场契合
- AI 让建造成本急剧下降 → 为什么还需要 $30M？
- "表演性创业"正在取代"创业"
