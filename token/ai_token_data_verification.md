## 置信度说明

| 评级 | 含义 |
|:---:|------|
| ★★★★★ | 多源交叉验证 + 官方数据——高度可靠 |
| ★★★★ | 官方来源或权威第三方——可靠 |
| ★★★ | 单一可靠来源或行业共识估算——中等可靠 |
| ★★ | 推算/估算/单一来源无法验证——需谨慎 |
| ★ | 纯猜测/方向性判断——不构成事实依据 |
