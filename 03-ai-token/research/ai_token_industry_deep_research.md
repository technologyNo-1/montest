## 一、Token 是什么 —— 技术定义与本质特征

### 1.1 技术本质

Token（令牌）是 LLM 处理和生成文本的**最小语义单元**。它不是字符，不是单词，而是一个"被词汇表编码后的子词片段"。

```
英文："I love AI"
  → cl100k_base tokenizer: ["I", " love", " AI"] = 3 tokens
  → o200k_base tokenizer: ["I", " love", " AI"] = 3 tokens

中文："我爱人工智能"
  → cl100k_base: ["æ", "Ĉ", 'ģ', ...] ≈ 8 tokens (严重碎片化)
  → o200k_base: ["我", "爱", "人工", "智能"] ≈ 4 tokens (大幅改善)
```

### 1.2 Token 生成机制（推理的两阶段）

LLM 推理分为两个物理上截然不同的阶段：

**阶段一：Prefill（输入处理）**
- 整个用户 Prompt 在一次正向传播中处理
- 计算类型：矩阵×矩阵乘法（GEMM）
- 瓶颈：**GPU 算力（FLOPS）**——计算密集
- GPU 利用率：>80%

**阶段二：Decode（逐 Token 生成）**
- 每个 Token N+1 必须等待 Token N 生成后才能开始——**严格串行**
- 计算类型：矩阵×向量乘法（GEMV）
- 瓶颈：**显存带宽（HBM Bandwidth）**——GPU 大部分时间在等待权重从显存加载
- GPU 利用率：15-40%

### 1.3 输入 Token vs 输出 Token 的成本非对称性

这是理解 Token 经济的第一个关键：**输出 Token 的价格是输入 Token 的 2-8 倍**。

| 模型              | 输入 ($/百万 Token) | 输出 ($/百万 Token) | 输出/输入比 |
| ----------------- | :-----------------: | :-----------------: | :---------: |
| GPT-4o            |        $5.00        |       $15.00        |     3x      |
| GPT-5.2 Pro       |       $21.00        |       $168.00       |     8x      |
| Claude Opus 4     |       $15.00        |       $75.00        |     5x      |
| Gemini 3.1 Pro    |        $2.00        |       $12.00        |     6x      |
| DeepSeek V4 Flash |        $0.14        |        $0.28        |     2x      |

**根因**：
- 输入可以并行处理 → GPU 效率高
- 输出必须逐 Token 串行生成 → GPU 效率极低（显存带宽瓶颈）
- Prompt Caching 让输入 KV Cache 可复用 → 输出每个 Token 的计算都是唯一的
- 量化（FP8/FP4）主要改善 Decode 速度

### 1.4 分词方法对成本的显著影响（"语言税"）

同一段文字，不同分词器/语言/模型会产生差异巨大的 Token 数量：

**GPT-4 `cl100k_base` tokenizer（同段文字）**：
- 英语：1.00x（基线）
- 中文：1.33x（+33% 成本）
- 德语：1.96x（+96% 成本）
- 日语：2.93x（+193% 成本）
- 阿拉伯语：3.30x（+230% 成本）

**GPT-4o `o200k_base` 大幅缩小差距**：阿拉伯语从 3.30x 降至 1.35x。

**新兴方案**：Byte Latent Transformer (Meta 2024)、AU-Net (NeurIPS 2025)、T-FREE——从字节级别动态分组，不再依赖固定词汇表。

### 1.5 关键业务落地推论（对应 Token 成本观测、Slock/TokenTally 场景）

- 输入、输出 token 分属两个物理完全独立的硬件阶段，因此 FinOps 工具必须分开统计两类 token 成本
- 缓存读写是 Prefill 阶段最大变量，高缓存命中率可大幅削减硬件算力消耗与账单，是企业降本核心抓手
- 分词器差异会造成同业务文本在不同模型间 token 成本差异，跨模型成本对比必须归一化字符粒度，不能直接对比原始 token 数量
- 长文档场景瓶颈永远在 Prefill（输入 token 平方级算力），长对话 / 代码生成瓶颈在 Decode（输出 token 线性累积）
- 本地多 Agent（Slock/OpenClaw）频繁复用同一代码库上下文，会持续产生大量 cache_read token，显著降低整体 Token 消耗

### 3.2 价格下降趋势

Token 价格自 2020 年以来经历了 **约 600 倍的下降**，但下降速度在减缓：

| 时期           | 降价幅度            |
| -------------- | ------------------- |
| 2020 → 2023    | ~200x 累计下降      |
| 2024           | 价格每 3-6 个月减半 |
| 2025 年上半年  | 月均降幅 ~10%       |
| 2025 年下半年  | 累计降幅 **39%**    |
| 2026 年 1-5 月 | 累计降幅仅 **6%**   |

**关键洞察**：美国前沿模型（GPT-5.4 Pro $180/百万 output）vs 中国模型（DeepSeek V4 Flash $0.015/百万 output）之间的价差高达 **12,000 倍**。这不是"美国更贵"——而是两个完全不同的市场结构。

### 3.3 成本结构拆解（1GW 级数据中心，4 年周期）

| 成本类别             | 占 TCO 比例 |
| -------------------- | :---------: |
| **GPU 硬件**         |   **45%**   |
| 电力与冷却基础设施   |     20%     |
| 网络                 |     9%      |
| 存储                 |     7%      |
| **电力（5 年消耗）** |   **~5%**   |
| 其他运维             |    <1.5%    |

**关键洞察**：**电力只占推理 TCO 的 ~5%**。主导成本是 GPU 硬件摊销（45%）+ 基础设施（20%）。但电力是**物理约束**——GPU 可以买更多，变电站容量不能。

### 3.5 影响单位 Token 成本的关键因素

**最显著的五项因素（按影响权重排序）**：

| 因素                  | 机制                                   |        成本影响         |
| --------------------- | -------------------------------------- | :---------------------: |
| **1. 模型规模**       | 7B→70B→405B 显存需求非线性增长         |       **10x-60x**       |
| **2. 量化等级**       | FP16→INT8→INT4→FP4                     | 每次约 **50%** 成本减半 |
| **3. Prompt Caching** | 共享前缀 KV Cache 复用                 |    **最多 90%** 降低    |
| **4. 批量大小**       | 连续批处理（Continuous Batching）      |   **3-10x** 吞吐提升    |
| **5. 推测解码**       | 用小模型预测多个 Token，大模型并行验证 |    **2-3x** 速度提升    |

**量化 + 推测解码 + 连续批处理 = ~80%+ 累积成本降低**（vs 原生 FP16 单流推理）

### 3.6 最优性价比定制芯片

| 芯片           |    Llama 3.1 8B 速度     |

## 四、Token 如何流动 —— 销售渠道与商业结构

### 4.1 销售渠道分层

| 渠道                                              | 收入占比（估算） | 特征                         |
| ------------------------------------------------- | :--------------: | ---------------------------- |
| **直接 API + 企业合同**                           |     ~35-40%      | 按量计费 + 承诺消费折扣      |
| **云市场（AWS Bedrock / Azure AI / GCP Vertex）** |     ~25-30%      | AWS Bedrock 单一 $550 亿 ARR |
| **消费者订阅（ChatGPT Plus / Claude Pro）**       |     ~20-25%      | 固定月费 + 用量上限          |
| **开源自托管（Together AI / Fireworks / Groq）**  |      ~5-10%      | 低利润率、规模化竞争         |
| **聚合器（OpenRouter）**                          |       新兴       | $13 亿估值，统一 API 网关    |

### 4.2 聚合器模式崛起

**OpenRouter** 是最重要的新商业形态——"Token 的 Stripe"：
- 连接 100+ 模型供应商
- 统一 API、统一计费、自动故障转移
- 估值 $13 亿（2026）
- 解决了"不要绑定单一模型供应商"的企业需求

**完整流转节点**
- 业务应用 (Slock/Zed/ 自研 AI SaaS) → OpenRouter 统一网关 → 底层模型厂商 (OpenAI/Anthropic/DeepSeek/Meta) → GPU 集群推理生成 Token
- 输入 Token 流向
  - 用户 Prompt、历史上下文、知识库、代码库文本 → Tokenizer 分词 → Prefill 阶段生成 KV 缓存 → 消耗输入 Token
- 输出 Token 流向
  - Decode 循环逐 Token 生成文本 / 代码 → 流式回传 OpenRouter 网关 → 网关实时计量 input/output/cache 读写 Token → 流式转发给前端 / 本地 Agent
- 缓存 Token 特殊分流
  - 重复上下文直接读取已有 KV 缓存，产生cache_read_token，跳过昂贵 Prefill；全新上下文生成cache_write_token，两类 Token 分开计量、分开计价
- 两套模式资金流（平台充值模式 / BYOK 自带密钥模式）
  - 开发者→Stripe 全球支付渠道→OpenRouter 账户余额 (积分 Credits)
  - 开发者持有原生 Claude/OpenAI API Key，流量仅经过 OpenRouter 路由层；厂商账单直接开给企业，OpenRouter 仅按月收取 5% 路由服务费，不触碰底层算力资金流

**完整落地体系**（技术落地 + 商业落地双维度）
- 技术层落地：统一网关路由，标准化 Token 流转调度
- 统一兼容层（底层标准化）
  - 全部模型强制兼容 OpenAI Chat Completion 标准接口，开发者仅需一套 SDK / 一行 JS snippet 接入；自动适配 Claude、DeepSeek、Gemini 差异化参数、缓存字段、token 计数规则，网关内部做协议转换，业务侧无感知
- 实时 Token 计量内核（核心引擎）
  - 内置多厂商原生 Tokenizer（tiktoken/SentencePiece），精准统一跨模型 token 口径，解决不同分词器带来的成本统计偏差
- 智能流量调度（改变 Token 消耗成本的关键能力）
  - 缓存粘性路由：重复上下文固定路由至同一厂商，最大化缓存命中率，大幅减少 cache_write 高成本 token
- 商业层落地：Stripe 深度绑定，完整 Token 金融结算体系
- 原生 Stripe 一体化支付链路
  - Stripe Projects CLI 一键创建 OpenRouter 账号、生成 API Key、自动绑定支付方式，无需网页手动操作，适配 Slock/OpenClaw 本地自动化 Agent 批量账号创建

**行业三大关键全新发现**
- 发现 1：Token 流量具备极强的地域分层结构性（出海核心结论）
- 发现 2：缓存 Token 是决定企业算力成本的第一变量，网关层可主动优化
- 发现 3：单一模型厂商绑定具备极高商业风险，多模型中立网关是刚需

**token产业存在周期性**
- 公理 1：Token 是算力的物理产出，有刚性边际生产成本
  - Token 无法凭空生成，每一个输入 / 输出 Token 都要经过Prefill+Decode 双阶段 GPU 计算，消耗芯片、显存带宽、电力、机房折旧四大物理资源
- 公理 2：需求遵循算力版杰文斯悖论，具备自我放大、波动弹性
- 公理 3：产业链三层传导，资本开支具备滞后反馈循环

### 5.1 Token 消费结构

| ------------------------------------------ | :-------------------------: | :----------------: |

### 5.2 Token 的需求弹性与杰文斯悖论

**核心观察：Token 需求展现强烈的杰文斯效应。**

> Token 价格每下降 10 倍 → Token 消费增长远超 10 倍

- 2024 年 1 月到 2026 年 3 月：**仅中国市场 Token 消费增长了 1,400 倍**（26 个月内）
- Agent 工作流 + 推理链使 Token 消耗按 **18.6x 倍数增加** vs 简单对话
- 一名使用 Claude Code 的开发者日均消耗 5,000-50,000 Token
- 一名重度 Agent 用户日均消耗 50,000-500,000+ Token

**这意味着：价格下降不是杀死了收入——而是爆炸性地扩大了市场。**

| 阶段                       | 半导体周期                         | Token 产业类似表现                                         |
| -------------------------- | ---------------------------------- | ---------------------------------------------------------- |
| **扩张期（2023-2024）**    | 芯片缺货 → 疯狂下单 → 供不应求     | GPU 短缺 → 所有人抢购 → 推理价格极高                       |
| **过热期（2025 初）**      | 库存堆积 → 双倍订购 → 产能过度投资 | 300+ GPU 云供应商涌入 → VC 补贴价格 → 部分以低于成本价出售 |
| **调整期（2025 中-至今）** | 价格下跌 → 弱手出清 → 产能整合     | AWS 降价 44% → H100 价格从峰值跌 64-75% → 并购加速         |
| **成熟期（进行中）**       | 供给侧整合 + 需求持续增长          | Neocloud 并购潮 + Anthropic 率先盈利                       |

### 6.2 领先指标

| 指标          | 当前信号（2026/07）                   | 含义                     |
| ------------- | ------------------------------------- | ------------------------ |
| GPU 订单量    | Blackwell 系列强劲，GB300 排产到 2027 | 训练 + 推理需求双引擎    |

### 6.3 周期位置判断

**当前处于：过热后的调整/整合期 → 向成熟期过渡。**

类似于 2001-2003 年互联网泡沫后的光纤宽带过剩 → 需求花了好几年才填满过剩的带宽——但**Token 需求的增速比当年的带宽快得多**，所以消化周期的速度可能更快。

## 十、核心结论

1. **Token 是 AI 时代的"字节"**——它是智能生产和消费的原子单位。理解 Token = 理解 AI 经济的物理基础。

2. **输出 Token 成本是输入 Token 的 2-8 倍**——因为输出是**串行的、显存带宽瓶颈的**——这一物理事实不会因为软件优化而消失。

3. **Token 价格下降了 ~600 倍（2020→2026），但下降速度在减缓**——硬件改进正在逼近物理极限，未来的成本下降更多来自软件优化（量化/推测解码/批处理）。

4. **杰文斯悖论完全成立**——Token 越便宜，消耗越多（26 个月 1,400 倍增长）。不是"市场缩水"而是"市场爆炸"。

5. **Agent 是 Token 增长的最强引擎**——Agent 消耗 18.6 倍于普通对话的 Token。Agent 正在从"一个有趣的 Demo"变成"最大的 Token 消费入口"。

6. **最大的利润不在 GPU 租赁——在模型 + 产品整合**。Anthropic 的毛利率（60-70%）远超裸 GPU 租赁商（15-30%）。但 NVIDIA 是所有人共同的"房东"——拿走了 TCO 的 45%。

7. **中国和美国正在形成两个日益分化的 Token 经济圈**——定价、商业模式、技术路线迥异。中国的 Token 几乎是免费的，美国的 Token 是高溢价的。这对全球 AI 产业有深远的地缘政治含义。

## 十二、深度补充：全球 Token 经济的三个生产模式 + 中国悖论 + 主权 AI（子 Agent 3 第二轮输出）

### 12.1 中国悖论：最多 Token，最少收入

中国占全球 OpenRouter Token 量 **~61%**，但 API 总收入不到 $50 亿——对比 Anthropic 一家 ~$470 亿 ARR。

**根因**：
- 中国 Token 是商品化的"数字电力"——接近边际成本定价
- 美国 Token 通过企业锁定 + 产品整合取得溢价定价
- **不是同样的东西——是完全不同的市场结构**

### 12.2 中国 $2,950 亿 AI 基建计划

2026 年 6 月：中国发布 **$2,950 亿国家 AI 数据中心网格计划**，目标 2028 年 80% 国产芯片。加上电力基础设施，**总投资可能超过 $7,400 亿**。

- 国产 AI 芯片市场份额：17%（2023）→ **41%（2025）→ >50%（2026 预测）**
- 华为昇腾 950PR：**推理性能是 NVIDIA H20 的 2.87 倍**
- NVIDIA 中国收入：从 95% 份额 → 实际上归零。计提 **$45 亿减值**——半导体史上最剧烈的市场份额逆转

### 12.3 出口管制的悖论：效率取代硬件

美国硬件领先扩大了 5x→17x，但**中国现在生产的 Token 总量超过了美国**。

原因：制裁倒逼架构创新。中国在 MoE（混合专家）架构上的优势，使得 **每单位 EFLOPS 的 Token 产出约为美国的 4 倍**。

DeepSeek V4：>1 万亿总参数，每 Token 仅激活 ~370 亿参数——**效率增益 4-7x**。

### 12.4 "智能鸿沟"：24.7% vs 14.1%

- 全球北方 AI 使用率：**24.7%** 人口
- 全球南方 AI 使用率：**14.1%** 人口
- 撒哈拉以南非洲：**全球 18% 人口，0.6% 数据中心容量**——计算缺口 98%（需要 4.2GW，当前路径仅 0.1GW）

### 12.5 中国的新兴市场算力战略

中国供应商在新兴市场算力采购中的份额：**27%（2025）→ 68%（2026 Q1）**

中国在出口推理基础设施作为地缘政治工具——以廉价 Token 换取发展中国家的影响力，而美国在提供昂贵硬件。

- **美国私营 AI 投资是欧盟的 ~6 倍**
- 欧盟仅 ~3 个基础模型 vs 中国 15 个
