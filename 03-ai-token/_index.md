## 核心发现速览
1. Token 是 AI 的「字节」；输出成本是输入 2-8 倍（解码串行）
2. 价格降 600 倍，消费涨 1400 倍——杰文斯悖论成立
3. Agent 消耗 ~1000x 对话 Token——增长最强引擎
4. 中国 61% Token 量，<1% 全球 API 收入——两个市场
5. 从「按 Token 计费」转向「按结果计费」——范式转变
