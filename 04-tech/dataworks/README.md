## 关键设计决策

| 决策 | 理由 |
|------|------|
| **LLM 不做 SQL 生成** | 直接 NL2SQL 业务准确率仅 48%，引入语义层可提升至 92%+ |
| **语义层是必选项** | 没有 AI-ready Data，就没有可落地的 NL2SQL |
| **多层验证** | 语法→Explain→结果→趋势→业务规则，层层把关 |
| **置信度评分** | `>=90%` 自动采纳、`70-90%` 标记复核、`<70%` 拒答 |
| **编译时安全** | 权限/脱敏/LIMIT 在 SQL 生成时注入，而非事后扫描 |
| **小模型优先** | 80% 场景用 3B-7B 小模型，显著降低成本 |

## 技术栈

| 层级 | 选型 |
|------|------|
| 后端 | Python FastAPI + Temporal |
| LLM | DeepSeek V4 / Claude (通过 LiteLLM 网关) |
| 语义存储 | PostgreSQL + pgvector |
| 向量检索 | Milvus |
| SQL 引擎 | sqlglot (解析/转换/方言) |
| OLAP | ClickHouse / StarRocks |
| 缓存 | Redis |
| 消息 | Kafka |
| 监控 | Prometheus + Grafana + OpenTelemetry |
